00 — About
這是什麼網站
鋼嵐工具站是《鋼嵐》（Metal Storm）的玩家自製資料站，把散在官網、遊戲內與各家公告裡的資料 收攏成一份可查、可比較、可追蹤的資料庫。目標很單純：想查一把武器的數值時，不用開三個分頁。
🔎

查得到

機師、機甲、武器、背包、模組、元件六大圖鑑，含技能效果、數值成長與彼此的關聯。

🗓️

跟得上

版本速覽、灰燼行動名單、卡池與活動檔期甘特圖，改版前後都知道自己在哪個階段。

🧮

算得出

彩甲升級規劃器、元件掉落總表等實用計算工具；完整的傷害模擬仍在開發中。

ℹ️ 關於這份文件 這份文件原本是網站的「開發規劃書」，用來追蹤整體進度。隨著功能陸續完工、開發改以 階段性計畫（PLAN） 逐項推進，「整體進度」已不再是看待本站的好角度。現在它改為網站概要總覽： 讓有興趣的人快速知道這裡有什麼、資料哪裡來、做到哪了。

📝

有些天賦數值經過人工修正

官方資料介面回傳的天賦文本是「晶片全點滿」狀態的數值，跟多數人帳號裡看到的不同。 這類條目由維護者改寫為通用敘述並鎖定保護，之後的自動更新不會把它洗掉。

🔄

資料會快取在你的瀏覽器

為了少連線、開得快，圖鑑資料會存在瀏覽器本機，並跟著資料版本號自動失效。 若剛改版而你看到的還是舊資料，重新整理一次即可。

🗓️

版本時間線來自官方公告

卡池與活動檔期由台版官方公告自動解析後，經人工審核才發佈，因此偶有延遲。 官方沒寫清楚的檔期，站上寧可留空也不猜。

🏛️

舊資料不刪

已下架的活動、早期版本的機體與當時的數值都保留著。這站同時是一份遊戲的編年紀錄， 而不只是「當前版本查詢器」。

⚠️ 仍請以遊戲內顯示為準 本站為玩家自製的非官方網站，與遊戲開發商、代理商無隸屬關係；遊戲名稱、圖像與文本的著作權均屬原權利人所有。 資料難免有誤或延遲，重要決策（例如要不要抽、要不要練）請對照遊戲內實際顯示。
03 — Status
目前做到哪了
本站已不再用「總體進度百分比」來管理。基礎查詢功能大致完工後，後續開發改以一個個 階段性計畫（PLAN） 推進，各計畫獨立立案、獨立完工。下面是概略的現況分層。
✅

已初步完工

六大資料圖鑑、版本情報三檢視、攻略與工具頁、登入與個人設定、手機版排版、 資料快取與載入效能、後台資料維護介面。日常查詢需求基本都能滿足。

🔧

持續改善中

多數進行中的計畫屬於「把已有的東西做得更好」：資訊架構調整、資料補完、 引用與詞條的互動體驗、後台編輯效率、使用統計與問題回報管道。

🧪

規劃中 / 尚未開放

傷害計算與配裝模擬、攻略文章系統、機甲故事館、機師形態變化與召喚單位展示、 槽位與裝備限制模型。這些是新板塊，時程視實際狀況而定。

📌 想看細節？ 每個計畫都有自己的計畫書與進度表，分為 執行中（正在做）、觀察維護中（做完了但要長期填資料或觀察）、 歷史記錄（已完成歸檔）三區。 → 階段性開發計畫

純前端 + 託管資料庫

⚡

三層快取，省連線也省錢

記憶體 → 瀏覽器本機 → 資料庫，配合每個集合的版本號決定要不要重抓。 多數瀏覽情境下不會真的連到資料庫。

🛡️

邊緣代理與存取控制

公開資料經由同源代理供應，並在邊緣做基本的來源檢查與流量限制， 以免資料被整包搬走或被灌爆額度。

文件 內容 公開狀態

🔒 技術文件為什麼不放上來 這類文件包含資料庫結構、安全規則與後台操作細節，公開的效益有限、風險卻不小。 它們不會被打包進網站，只保留在原始碼庫中供維護者查閱—— 也就是說，網站上根本沒有這些檔案，而不是「藏起連結」而已。 因此，其他文件裡若有連結指向技術文件、或指向已下架的舊文件（例如早期的「開發進度表」， 其 Phase 1–8 制已被 PLAN 制取代），點了會找不到頁面，這是正常的。
💬 其餘文件歡迎自由取閱 公開的文件放著就是給人看的：想知道某個功能當初為什麼這樣設計、某個改版做了什麼取捨， 翻對應的 PLAN 計畫書通常都寫得比這頁詳細。內容以撰寫當下的想法為準，可能與最終實作有出入。
