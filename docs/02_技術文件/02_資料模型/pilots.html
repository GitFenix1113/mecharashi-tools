▎技能列表 skills[]：string[]（PLAN-004）— pilotSkills 集合文件 ID 陣列
PLAN-004 技能庫抽離後，skills 改為 pilotSkills 文件 ID 陣列（單一資料源），技能本體存於 pilotSkills 集合。共用技能（如職業被動）多位機師指向同一文件，編輯一次全站生效。以下欄位為被引用的 PilotSkillDoc（與舊嵌入 PilotSkill 同構，另有頂層 id）。涵蓋仿生電腦各核心單元解鎖的所有技能。
 ├ namestring技能名稱
 ├ typeSkillType (Enum)技能類型：被動技能 / 主動技能 / 指令技能（Order，有 CD）
 ├ apstring?AP 消耗；主動 / 指令 / 必殺 / 武器技能適用
 ├ cdstring?冷卻回合數；指令技能才有，對應 API 的 CD 欄位（計算器不用此欄位，僅供顯示）
 ├ weaponstring?限定武器類別；主動技能中需特定武器者填入，對應 API matchingWeaponType
 ├ descriptionstring效果描述文字（遊戲原文，含 [xxx] 標記）
 ├ descriptionRefsDescriptionRefs?描述內 [xxx] → 實體引用側錄（PLAN-019 Layer 1）
 ├ icon / iconLocalstring技能圖示路徑
 ├ effectsSkillEffect[]可量化效果列表（空陣列 = 待填入）；計算器加總所有 active 技能的 effects
 ├ buffIdsstring[]技能觸發的 Buff ID 列表（API BufCarried 以 "/" 分割轉換）
 └ manualboolean?後台手動新增的技能（機師天生自帶、官網查無者）。true = 後台可編輯 name / type / ap / cd / description，爬蟲補丁模式不覆寫亦不刪除；未設定 / false = 由爬蟲管理，後台僅能編輯 effects / buffIds
▎天賦列表 talents[] — PilotTalent（PLAN-001）
 ├ namestring天賦名稱
 ├ typestring技能類型（通常為「被動技能」）
 ├ descriptionstring初始（0–2 星）效果描述
 ├ descriptionMaxstring滿星（3–5 星）效果描述
 ├ icon / iconLocalstring技能圖示路徑
 ├ effectsSkillEffect[]可量化效果列表（空陣列 = 待填入）
 ├ enhancedEffectsSkillEffect[]?裝備專屬武器後的加強版效果（計算器用）；省略或空陣列表示無加強版
注意：天賦強化後的顯示文字差異由 WeaponSkill.enhancedTalentDescription 負責（PLAN-005），此欄位僅用於計算器數值加總
 ├ buffIdsstring[]天賦觸發的 Buff ID 列表
 ├ manualboolean?正文經人工去污染（官方 API 天賦文本可能為「滿晶片狀態」，如艾達 7層/5AP/星爆 皆為 γ2≥16 值）；true 時爬蟲補丁不覆寫 description / descriptionMax（語意比照 PilotSkill.manual）
 └ ndVariantsTalentNdVariant[]?神經驅動算力改寫變體（PLAN-021）；省略 = 無。每筆 = minSum（算力門檻，對應 NeuralDriveLevel.minSum）＋ zone?（門檻所屬分區名，如 'γ2'；同機師多區可能有相同 minSum，缺 zone 會歧義）＋ label?（顯示標籤，省略則生成「γ2 算力 ≥ N」）＋ description（改寫後天賦正文，初始星級版）＋ descriptionMax?（滿星版改寫正文，含滿星專屬子句；省略時前台退回 description 並提示待補）＋ descriptionRefs?（與天賦 descriptionRefs 合併解析）
前台天賦卡頂部有「初始天賦 ⇌ 最大強化」切換鈕（預設初始；最大強化版 DiffHighlight 對初始高亮）。另有「神經驅動算力配置列」（NdPowerBar，tab 卡頂部三分頁常駐）：玩家點選各區 Lv，依「該 zone 算力 ≥ minSum 取最高」即時改寫敘述、以 DiffHighlight 高亮差異（對照基準跟隨初始/最大切換）；γ 區合計受 ND_RULES.gammaPairCap=23 約束；多階互斥、計算器取最高（對應 buff 共用 GameBuff.mutexGroup）；資料走 manual 手動維護
▎神經驅動 neuralDrive[] — NeuralDrive（PLAN-001；能力內容 PLAN-023 抽離至 neuralDriveAbilities）
 ├ namestring神經驅動區塊名稱（如 α / β / γ1 / γ2）
 ├ iconstring圖示路徑
 ├ slotsstring[]插槽類型說明列表
 └ levels[] — NeuralDriveLevel（每個激活閾值）
   ├ levelnumber激活層級（1 起；α / β 分區最多 3 層，γ 分區最多 6 層）
   ├ minSumnumber最低激活算力值；α / β 通常為 1 / 4 / 7，γ 可達 1 / 4 / 7 / 10 / 13 / 16
   ├ abilityIdstring?🆕 PLAN-023 雙格式：填了則本層能力內容由 neuralDriveAbilities 此 ID 提供（單一資料源），以 resolveNeuralDriveLevel() 解析；未填 = 沿用下方嵌入欄位（舊格式）。已對全 82 機師 flip 補上，嵌入欄位保留為安全網（resolve 優先 abilityId、查不到回退嵌入）
   ├ effect / skillName / skillIcon / iconLocalstring嵌入舊格式：效果文字與被動名稱／圖示。flip 後由 abilityId 對應能力提供，此處為安全網備份
   ├ effectsSkillEffect[]嵌入舊格式可量化效果（多為空；flip 後改由能力庫提供）
   ├ buffIdsstring[]嵌入舊格式：激活此層觸發的 Buff ID
   └ descriptionRefsDescriptionRefs?🆕 PLAN-023 N2-1：描述內 [xxx] 引用側錄；flip 後由 resolve 從能力庫帶入，使神驅描述的 [xxx] 可點擊
