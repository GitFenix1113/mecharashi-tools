globalResearch全域科研 · GLOBAL RESEARCH

機師科研（依職業）/ 機甲科研（依裝甲）/ 武器科研（依種類）— 玩家自行輸入等級

NEW v1.1
設計說明
全域科研系統概覽
全域科研因玩家不同而異，網站提供「科研設定」頁讓玩家手動輸入自己各項科研的等級，系統自動計算對應加成。
⚠ 三個欄位都是 Array，不是 Record（PLAN-052-A D-2 修正）
src/types/research.ts 原本宣告成 Record<string, …>，於是 gr.pilotResearchByClass['格鬥家'] 恆為 undefined——而 tsc 完全不會抱怨 （索引一個 Record 本來就允許查無）。線上資料從第一天就是 Array，元素帶 className / armorType / weaponType 判別欄位。

⚠ mechResearchByType 的鍵是「中型」，不是「中甲」
本表沿用官方科研頁的用詞（輕型／中型／重型，與 MechLicense 同）， 而 Mech.armorType 是 ArmorType（輕型／中甲／重型）。只有中階不同名， 於是 find(x => x.armorType === mech.armorType) 在測試資料裡看起來正常、上線後 36/90 台中甲靜默拿 0 加成。
一律走 findMechResearch()（src/utils/normalizeArmorType.ts），不要自己比對。 刻意不改資料：「中型」是官方用詞不是打錯，改成「中甲」等於用站內詞彙覆蓋官方說法， 而且任何一支 seed／匯入腳本重跑就會寫回來。

⚠ 本集合不可刪
兩份盤點曾誤判它為「零消費端可移除」。它是全庫唯一填滿的公式數值表 （六職業／三裝甲／五武器種類全有值），對照全庫 SkillEffect 是 0/225 buffs、0/841 skills。 今天沒有消費端只代表傷害模擬還沒做。
📋 玩家輸入機制 登入用戶的科研設定存於 Firestore users/{uid}/profile.globalResearch，下次登入自動帶入。
未登入用戶的科研設定暫存於 localStorage。
globalResearch Collection 定義的是加成的計算規則（定義表），不是玩家個人資料。
Schema — 機師科研
pilotResearchByClass（依職業分類）
欄位型別說明
classNamestring（PilotClass 值域）職業名。實測只有 6 個：格鬥家／突擊手／狙擊手／戰術家／守護者／機械師
⚠ 沒有「調構師」——海莉絲與後續調構師一律查不到加成。findPilotResearch() 對此回 null，呼叫端應呈現為「這個職業還沒有科研資料」，不是「加成為 0」。
▎固定值加成 flatBonus（滿等級時的數值）
 ├ meleenumber格鬥素質 +（如 +2244）
 ├ defensenumber防禦素質 +（如 +2244）
 ├ assaultnumber突擊素質 +（如 +1800）
 └ …number其他素質對應加成
▎百分比加成 percentBonus
 ├ meleenumber格鬥素質 × %（如 +20%）
 └ …number其他素質對應百分比加成
Schema — 機甲科研
mechResearchByType（依裝甲類型分類）
欄位型別說明
armorTypestring裝甲類型（輕型／中型／重型）
⚠ 不是 ArmorType：這裡是「中型」，Mech.armorType 是「中甲」。查詢一律走 findMechResearch()，見本頁頂端的警告。
▎固定值加成 flatBonus（滿等級時）
 ├ torsoHPnumber軀幹耐久 +（如 +6029）
 ├ legHPnumber腿部耐久 +（如 +4529）
 ├ leftArmHP / rightArmHPnumber手臂耐久 +（如 +3035）
 ├ antiCritnumber抗暴 +（如 +2164）
 ├ evasionnumber閃避 +（如 +2544）
 ├ accuracynumber命中 +（如 +1698）
 ├ firepowernumber火力 +（如 +2944）
 ├ torsoArmornumber軀幹護甲 +（如 +294）
 └ legArmornumber腿部護甲 +（如 +196）
▎百分比加成 percentBonus
 ├ torsoHP / legHP / …number耐久 × %（如 +19%）
 └ firepower / antiCrit / …number火力/抗暴等 × %（如 +9%）

欄位型別說明
weaponTypestring武器種類（刀劍/拳套/重機槍…）
▎加成 bonus

 ├ accuracynumber命中 +（如 +1900）
 └ critnumber暴擊 +（如 +2598）
