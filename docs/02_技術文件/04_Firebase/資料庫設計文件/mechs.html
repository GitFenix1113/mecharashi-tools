02 — Relations
關聯說明
🔗 模組引用 mechs document 透過 module4Id、module8Id、moduleFixedIds[] 引用 modules collection 中的模組文件 （moduleFixedIds 含機甲副模組與機甲專屬模組兩類，靠 module.slot 分流，不要看 id 前綴）。 查詢特定機甲的副模組時，可使用 modules collection 的複合索引 boundMechId + boundPart 反向查詢。

⚠ 這三個欄位只有 id，沒有部位、也沒有等級。遊戲裡一顆天生模組的等級是四個部位各自貢獻的加總， 而那張矩陣（90 台 × 4 部位 ≈ 1500 格）刻意不落盤、由 src/utils/innateModules.ts 的規則算出， 例外才落在 parts.{position}.innateModules（PLAN-052-K）。 對帳腳本：node scripts/check-part-module-drift.mjs。
