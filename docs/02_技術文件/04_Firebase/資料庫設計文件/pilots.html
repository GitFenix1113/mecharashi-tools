🗃️ pilots — 機師資料
欄位型別說明
idstring文件 ID。格式 pilot_<3 位流水號>_<名稱 slug>（如 pilot_001_葉夫根尼）。爬蟲以「API 清單位置 +1」編號；後台新增時由 makeNumberedEntityId 續既有最大號 +1，slug 規則同 idSlug.ts。全 88 筆皆帶號（001–088）、無缺號無重號——後台早期手建的 6 筆不帶號 ID（pilot_安／pilot_曜…）已於 2026-08-18 遷移補號，舊文件留存於 archiveIdMigration 集合
namestring顯示名稱
fullNamestring完整全名
gameIdstring?🆕 PLAN-054：機師卡 Icon_item_<gameId>A 編號（只有可抽機師有）；官方原檔資料夾 game/pilots/<gameId>/。與 artKey 不互推（例外 5 位：維娜、貝爾莎、阿列娜、珂賽特、瑪阿特）。未設定＝還沒有機師卡（NPC 轉正、官方還沒出卡也可能）
gameRefPilotGameRef?🆕 PLAN-065-A：遊戲身分鍵——機師記錄 ID（pilotInfoId），傷害模擬用。選填；與 gameId 不同、不互推。由 scripts/backfill-game-join-keys.mjs 回填，後台唯讀顯示；未設定＝未連結。型別見 src/types/gameRef.ts
artKeystring?🆕 PLAN-054：預設立繪主鍵（如 Pilot_10103174A），與官方檔名逐字相同；_half／_head／_Raw 接在後面。2026-10-12 起也可以指到 NPC 圖庫 game/npc/（NPC 轉正、尚無機師卡時）
pairedMechIdstring?🆕 PLAN-054：官配機甲的文件 ID（61 位有值）。只存機師側，機甲側由 pairedPilotOf() 推導
rarityItemRarity稀有度 Enum：S / A / B（機師不使用 EX）
classPilotClass職業 Enum：突擊手 / 狙擊手 / 戰術家 / 格鬥家 / 守護者 / 機械師 / 調構師
factionstring所屬勢力。PLAN-042-E 站長 Q1：留在 pilots（日後會有機制作用），故事館卷宗也讀這一欄
licenseMechLicense駕駛許可 Enum：輕型 / 中型 / 重型
masterLevelstring駕駛等級（如 "大師Ⅲ"）
statsobject滿級六維 { melee, assault, shooting, tactics, defense, engineering }
statsBaseobject初始六維（同結構）
apobject滿級 AP { init, max, recovery }
apBaseobject初始 AP（同結構）
talents[]array天賦列表（嵌入式，見下方 SkillEntry 結構）
skills[]string[]技能 ID 陣列（PLAN-004 單一資料源）：指向 pilotSkills 集合 的文件 ID；共用技能多位機師指向同一文件，編輯一次全站生效。過渡期相容嵌入舊格式（resolvePilotSkills 解析），Stage 2 flip 後收斂為純 ID
neuralDrive[]array神經驅動列表（嵌入式，見下方 SkillEntry 結構）。PLAN-023 進行中：將比照 skills 抽離為 neuralDriveAbilities 能力庫（能力名為鍵），level 改引用 abilityId
attacknumber攻擊素質
defensenumber防禦素質
portraitstring立繪圖片路徑
manualboolean?🆕 PLAN-025：後台手動新增的機師（官方資料更新前自建，ID 以 pilot_<NNN>_<名> 續號生成）。true = 爬蟲補丁模式（scrape-pilots-v3.js）整筆略過、不覆寫或刪除；純作後端防覆寫，前台不因此顯示標記。語意比照 pilotSkills / talents 的 manual
▎已遷出 / 待刪的舊欄位（PLAN-042-E，2026-10-13）
新判準（決策一，取代總綱決策二）：與數值、機制有關的留在 pilots，其餘歸 pilotLore；圖鑑只讀 pilots（單向依賴）。 下列欄位已從 Pilot 型別移除，DB 裡的舊值在 G-1（部署後一週）由腳本刪除；在那之前仍會隨文件讀回，但沒有任何程式讀它們
lorestring→ pilotLore.intro（扉頁簡介，尾端署名已切到 frontSource）。純文字，從來不是 Markdown
profileobject→ pilotLore.dossier（性別／身高／血型；additionalInfo map 改為有序陣列 extra）。新建機師也不再產生空的 profile
nameEnstring?→ pilotLore.nameEn
fullPortraitstring?孤兒欄位（舊爬蟲的 _Raw 路徑，沒有任何讀取點），不搬，G-1 一起刪
