01 — 用途
pilotSkills Collection
📌 用途說明
PLAN-004 技能庫抽離前，技能以嵌入方式存於每個 pilots 文件的 skills[]（同名共用技能各存一份副本）。
抽離後，技能本體集中存於 pilotSkills 集合（單一資料源），Pilot.skills 改為此集合的文件 ID 陣列。
· 共用技能（如職業被動「協同作戰1」）多位機師指向同一文件 → 編輯一次全站生效。
· 技能可被任意描述中的 [xxx] 引用（PLAN-019 refType:'skill'）→ 懸停／點擊顯示 icon、類型與效果。
· 前台讀取走 GameDataContext 一次預載 + PLAN-017 版本快取（回訪 0 讀取）。

欄位型別說明

apstring?AP 消耗；主動 / 指令 / 必殺 / 武器技能適用
cdstring?冷卻回合數；指令技能才有
weaponWeaponRequirement | string?限定武器需求；武器技能才有
descriptionstring效果描述文字（遊戲原文，含 [xxx] 標記）
descriptionRefsDescriptionRefs?描述內 [xxx] → 實體引用側錄（PLAN-019 Layer 1）
icon / iconLocalstring技能圖示（遠端 URL / 本地 /images/skills/…）
effectsSkillEffect[]可量化效果列表（空陣列 = 待填入）；計算器加總用
buffIdsstring[]此技能賦予的 BUFF ID 列表 → 引用 buffs 集合（PLAN-019 Layer 2 賦予邊）
manualboolean?後台手動新增（機師天生自帶、官網查無 / form-gated 條件技能）。爬蟲補丁模式不覆寫亦不刪除
