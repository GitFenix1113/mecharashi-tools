館首頁 /lore

列 pilots 全員而不是列 pilotLore——牆是「名冊」：名字、職業、版本、立繪都是 pilots 的身分欄位，pilotLore 只拿來疊章節數與陣營徽章角標； 讀不到 pilotLore 時牆照樣完整（只少了角標）。PLAN-042-E 搬遷時每位機師都建了一份 pilotLore，點進去不會是空頁。 依職業（CLASS_CONFIG 順序）或登場版本分組；卡片＝縮圖（與 /pilots 同一組 URL、瀏覽器快取直接命中）＋底部漸層＋職業色條； 有（非草稿的）章節才出現「N 章」徽章，章數經 publishedChapters() 計算、草稿章不計入。賽拉沒有圖片資料夾，牆上照樣留位、顯示「尚無立繪」。機甲分頁預留給 042-B。

扉頁 /lore/pilots/:id

PLAN-042-D 起改為「舞台＋卷宗」：立繪是固定在視窗的舞台（sticky 全高層＋負 margin，仍在唯一 scrollport 裡），往正文方向漸隱； 卷宗是一疊半透明紙卡（標題區、扉頁、個人資料、逸聞目錄）從另一側蓋上來、蓋住漸隱帶。構圖在渲染前分流成 tall／wide／official／scene（loreStageArt.ts）， 立繪站哪側看 LORE_ART_TUNING.side。修掉了半身圖機師正文被擠到 293px 的問題。舞台外側有外觀列與「全身立繪」鑑賞模式。
PLAN-042-E 起卷宗的資料來源：標題區的身分欄位（名字、全名、職業、陣營、執照、天賦）讀 pilots；英文名、扉頁簡介＋署名、個人資料、徽章、逸聞目錄全部讀 pilotLore。 簡介在搬遷時已切掉署名，渲染端不再跑 stripTrailingSource；個人資料列由 dossierRows() 組出（性別→身高→血型→陣營→自訂欄位，順序＝編輯台排的順序）。 pilotLore 載入中／失敗時，扉頁卡改顯示「檔案調閱中」／「故事資料載入失敗」＋重新整理鈕，個人資料與逸聞卡不出現。
（以下為 042-A 的舊版面，已被取代）桌機 42／58 兩欄：左立繪柱（sticky，高度吃 --lore-viewport-h 實測值）、右卷宗。立繪在渲染前分流： 52 位有 art.webp 走直式全身（hasPilotArt），其餘退回 full.webp 半身並套底部噪點 mask（86/87 張底邊硬切）。 直書姓名壓立繪右緣；職業／名字／三枚徽記（陣營文字圓環、天賦圖示、駕駛許可）；引文體正文套 blockquote 語彙、署名右對齊細線；additionalInfo 鍵值列；章節入口。 手機改上下堆疊，立繪上方 sticky 38vh。

章節頁 /lore/pilots/:id/:part

PLAN-042-D：閱讀模式——立繪往外退、彩圖淡出、線稿當底紋，稿紙置中（描邊大章號、懸掛引號、首字放大、署名細線、旁白便條、頂端閱讀進度條）； 章節軸改膠囊樣式；← → 換章、Esc 回檔案。
與扉頁同一個元件，版面骨架只寫一份。常駐具名章節軸（sticky）＋◀▶＋頁碼；換章靠點按鈕／鍵盤左右／手機水平滑動三種明確意圖，絕不接滾輪（PLAN-050 拆舊輪播的教訓）。 扉頁→第一章 push、章節之間 replace。正文走 LoreRichText（只解析 [xxx]，不套數字高亮）、署名、NPC 旁白列（speaker 查不到只少頭像不消失）、「下一章」列。只有一章時整套底盤不掛。
草稿章（PLAN-042-E）：LoreChapter.draft 為 true 的章不進目錄、章節軸與 ‹ ›；草稿章或打錯／已移除的章節網址等 pilotLore 有結果後 replace 導回扉頁。前台唯一的過濾點是 publishedChapters()。

切換列與機師名冊（PLAN-042-D）

詳情頁底部膠囊：可橫捲的圓形頭像列（目前這位置中）、‹ ›、序號、「名冊」；← → 換人（閱讀模式中換章）、手機封面左右滑。 平常半沉在視窗底緣、只露出上半截（2026-10-13 站長回饋：減少版面佔用）：滑鼠移上去或鍵盤焦點時升起；觸控點一下先升起（這一下不換人），捲動館內或點列外再收回。 名冊從膠囊長出來、頭像 FLIP 飛進分組格子；搜尋（含英文名——PLAN-042-E 起取自 pilotLore，由 withLoreNames() 依 id 併進名冊成員）、依職業／登場版本分組（與館首頁同一個排序，記在 sessionStorage）、有逸聞／有外觀篩選、/ 開啟、Esc 收合。 換人網址用 replace；回館首頁時 LoreLayout 會還原牆面的捲動位置（POP）。換人過場 0.9 秒、不重播完整開場；完整開場只在進入詳情頁時播。

外觀切換（PLAN-042-D）

36 位機師 40 套造型＋NPC 圖庫裡有外觀卡的 2 套（海莉絲、瑪阿特）。外觀列用造型自己的 _head（外觀卡是袋裝商品圖不用）；換外觀只換舞台、正文不重進場（新的那套由上往下擦入）； 場景插畫外觀走 scene 構圖。官網 8 位的官方名字層只配預設立繪，換外觀後改用直書名＋簽名。網址 ?skin=，同一次瀏覽換人再回來會記得。
名稱、隱藏、順序來自 DB（PLAN-042-E）：讀 pilotLore.skins，後台存檔即生效、不必部署；沒設定的外觀照原索引接在後面、顯示「外觀 N」（N＝build 清單原索引，不隨排序或隱藏變動）。 「隱藏」只是不列出，圖仍在打包檔裡。pilotLore 讀不到時照圖檔層原樣列。預設外觀＝pilots.artKey，不由故事館管。

編輯台 /admin/lore

PLAN-042-E 起是「故事館編輯台」：一位機師的故事資料全部在這裡編（機師管理的「個人資料」分頁已移除）。 列表列出 pilots 全員＋從資料推導的進度標籤；網址 ?pilot=<id> 直接開該位的編輯面板（開關同步網址）。 面板四個分頁：扉頁／人物檔案／逸聞章節／外觀，右欄是渲染真前台元件的即時預覽（細節見下方設計備註）。 寫入走 saveWithHistory（整份覆寫、自動 bump 版本），章節錨點用 { by: 'key' }（LoreChapter 沒有 name，錨錯欄位每筆都會 anchorMismatch）。沒有刪除路徑。
