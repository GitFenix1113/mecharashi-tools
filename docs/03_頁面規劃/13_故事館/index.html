館首頁 /lore

列 pilots 全員（90 格）而不是列 pilotLore——後者現階段是 34 份空殼，列它牆會少掉 55 位有扉頁可讀的機師。 依職業（CLASS_CONFIG 順序）或登場版本分組；卡片＝縮圖（與 /pilots 同一組 URL、瀏覽器快取直接命中）＋底部漸層＋職業色條； 有章節才出現「N 章」徽章。賽拉沒有圖片資料夾，牆上照樣留位、顯示「尚無立繪」。機甲分頁預留給 042-B。

📄

扉頁 /lore/pilots/:id

桌機 42／58 兩欄：左立繪柱（sticky，高度吃 --lore-viewport-h 實測值）、右卷宗。立繪在渲染前分流： 52 位有 art.webp 走直式全身（hasPilotArt），其餘退回 full.webp 半身並套底部噪點 mask（86/87 張底邊硬切）。 直書姓名壓立繪右緣；職業／名字／三枚徽記（陣營文字圓環、天賦圖示、駕駛許可）；引文體正文套 blockquote 語彙、署名右對齊細線；additionalInfo 鍵值列；章節入口。 手機改上下堆疊，立繪上方 sticky 38vh。

📖

章節頁 /lore/pilots/:id/:part

與扉頁同一個元件，版面骨架只寫一份。常駐具名章節軸（sticky）＋◀▶＋頁碼；換章靠點按鈕／鍵盤左右／手機水平滑動三種明確意圖，絕不接滾輪（PLAN-050 拆舊輪播的教訓）。 扉頁→第一章 push、章節之間 replace。正文走 LoreRichText（只解析 [xxx]，不套數字高亮）、署名、NPC 旁白列（speaker 查不到只少頭像不消失）、「下一章」列。只有一章時整套底盤不掛。

🛠️

編輯台 /admin/lore

章節新增／排序／改標題／獨立刪除；整篇貼上後切段成章（不做程式自動判斷，只提供輔助）；自動清掉 OCR 常見的軟換行與全形空白；列表加「章節數」欄。 寫入走 saveWithHistory，章節錨點用 { by: 'key' }（LoreChapter 沒有 name，錨錯欄位每筆都會 anchorMismatch）。

設計備註
開發注意事項
✅ 已實作（PLAN-042-A Phase C–F）
· 唯一 scrollport：Layout 的 <main> 是 overflow-hidden 的假 scrollport，館內任何 position: sticky 都會失效；故 LoreLayout 自己開 .lore-scroll，高度沿 flex 鏈傳下來（不做 calc(100vh - …) 減法，SignedOutBanner 的高度算不到）。 館內元件不得再開第二層 overflow-y，兩條垂直捲軸並存時外層永遠捲不動
· 跨路由捲頂由 LoreLayout 監聽 pathname 統一負責（它全程不卸載）；章節軸自動對位只對本列 scrollTo，不用 scrollIntoView（會順手捲掉外層）
· 守衛順序 error → loading → 內容：GameDataContext 抓取失敗時 loading 恆為 true，反過來寫永遠看不到錯誤分支
· 顯影元件 LoreArt：灰階層＋反相模糊 color-dodge 層＝偽線稿，彩圖 opacity 淡入；只動 opacity 不動 filter；LORE_ART_TUNING 以圖片資料夾名為鍵（「零」關閉線稿）；reduced-motion 直接 display:none 線稿層
· 色票：紙色只覆寫 .lore-shell / .lore-chrome，accent 八色不覆寫（稀有度／職業語意色）；三處硬寫的同款顏色改色時要一起改（index.css 註解列出）
· Worker：/lore/* route、parseEntityPath 以第二條正則吃四段路徑（不放寬圖鑑那條）、故事館 OG 卡換 title／description、og:image 沿用立繪
⚠ 上線前置（不在程式碼裡，build／test 抓不到）
· cd workers && npx wrangler deploy（/api/data/pilotLore 由 404 轉 200、/lore/* route 生效）
· npx firebase deploy --only firestore:rules（後台級聯刪除走 SDK 直連，未部署會整個失敗）
· Cloudflare Transform Rule 白名單加 /lore（CLAUDE.md 規則 3），否則真人拿到 HTTP 404、社群預覽 route 零命中
🔜 已知問題與後續：PLAN-042-C 故事館氛圍層
顯影動畫「看不見」有三個真因（時間軸從掛載起算不等圖片載入、線稿被關在黑框裡、只動 opacity 沒有運鏡）， 以及官網特色（名字書法、粒子、背景）的移植，全部收在 PLAN-042-C。盤點報告：_local-notes/2026-09/2026-09-16_機師故事館_美化工程盤點.html（本機不進版控）。
