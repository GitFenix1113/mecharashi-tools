技能 / 天賦 / 神經驅動（tab 卡）

三分頁卡片：各技能效果展示；技能類型以顏色區分（主動=紅、被動=藍、指令=紫），並顯示 AP 消耗、CD 冷卻、武器限制標籤。三個分頁皆具互動改寫：天賦／神經驅動為整段正文換寫（PLAN-021），技能分頁自 PLAN-034 起，其 [buff] 引用的階級也會隨算力同步抬升（改的是 chip 字面與浮窗資料，不是整段正文）。詳見下方「神經驅動算力 & 天賦改寫」與「數值引用層」區塊。
PLAN-041（2026-08-12）：分頁狀態改由網址 ?tab= 決定，不再是元件內部 state——重新整理、返回、分享連結都會停在同一個分頁（切換時以 replace 寫回，不堆積返回步驟）。分頁清單改為具名陣列 + derived active（找不到就落回第一個分頁），條件式分頁（下述「形態」）才不會在切換到沒有該分頁的機師時渲染出空白卡。分頁列亦已支援窄螢幕橫向捲動。

🔀

形態（條件式第 4 分頁 · PLAN-041）

僅當該機師有形態資料時才出現（判斷依據是 forms.length > 0，不是 class === '調構師'——官方職業 icon 跳號，且實測 2/82 機師的 class 與職業機制對不上）。
每張形態卡分三段各自標來源、不聚合成單一數值：形態固有（形態自身正文，永遠生效）／形態增益（天賦滿星另給、觸發後移除）／模組加成（如帕姆斯陣列，標明來源與等級）。
另有跨分頁常駐的「特殊能力」badge 列（與 NdPowerBar 同層），點擊跳至形態分頁。
兩個必須標註的特例：突擊形態的「子彈數+1」與帕姆斯陣列同名加成可疊加（已實測）；虛粒子形態同時獲得三份形態增益（此規則只寫在「粒子爆發」正文裡，不標的話玩家在該卡上找不到增益）。

🎚️

神經驅動算力配置列（NdPowerBar）

tab 卡頂部常駐的算力分區（α / β / γ1 / γ2…）配置列。玩家點選各區 Lv，依「該區算力 ≥ 門檻取最高」即時改寫天賦敘述。γ 區合計受上限約束（ND_RULES.gammaPairCap），超額顯示警告。

⇌

天賦卡「初始天賦 ⇌ 最大強化」切換

天賦卡頂部切換鈕（預設「初始」）。桌面版可雙欄並列初始／最大強化；手機版一次顯示一版。最大強化版以 DiffHighlight 對初始敘述高亮差異。

▶

神經驅動強化 / 專武強化敘述

天賦卡下方「神經驅動強化」「專武強化」區塊：依配置列狀態（ndVariants）／是否配備專武（enhancedTalentDescription）顯示改寫後敘述，並以 DiffHighlight 標出與目前主敘述的差異；對照基準跟隨初始／最大切換。

⬆

BUFF 階覆寫（PLAN-034，跨分頁生效）

算力達門檻時，該機師頁所有指向該 buff 家族的 [xxx] 引用同步抬升階級——技能分頁也算在內。原本「天賦說凝勢Ⅲ、技能說凝勢Ⅰ」的斷裂由此消失（技能正文沒有 ndVariants 這種整段換寫機制，只能靠引用層解）。
抬升的 chip 加雙底線標記與 title「已由 γ2 算力自 Lv1 提升至 Lv3」——技能區是使用者對照官方 wiki 最頻繁的地方，字換了卻沒有標記等於製造假訊息。
ND 能力卡本身不受影響（NdOverrideEmpty 隔離）：「凝勢可疊加7層」是規則宣告句，不該被自己宣告的規則改寫。

⚠

抬升不是全站不變式

實機確認：官方不同角色的文案由不同人撰寫，有些機師的技能敘述會隨算力改寫、有些不會。故「同頁階級一致」是本站呈現的內部一致性保證，而非「官方一定也這樣顯示」。官方在該處不改寫的引用點須逐筆以 EntityRef.fixedLevel 釘死，否則本站會顯示出遊戲裡看不到的階名。
