PLAN-021
神經驅動算力 & 天賦改寫
天賦正文會隨「神經驅動算力」配置與裝備專武而就地改寫。詳情頁把這層互動結構化呈現。
🎚️

神經驅動算力配置列（NdPowerBar）

tab 卡頂部常駐的算力分區（α / β / γ1 / γ2…）配置列。玩家點選各區 Lv，依「該區算力 ≥ 門檻取最高」即時改寫天賦敘述。γ 區合計受上限約束（ND_RULES.gammaPairCap），超額顯示警告。

⇌

天賦卡「初始天賦 ⇌ 最大強化」切換

天賦卡頂部切換鈕（預設「初始」）。桌面版可雙欄並列初始／最大強化；手機版一次顯示一版。最大強化版以 DiffHighlight 對初始敘述高亮差異。

▶

神經驅動強化 / 專武強化敘述

天賦卡下方「神經驅動強化」「專武強化」區塊：依配置列狀態（ndVariants）／是否配備專武（enhancedTalentDescription）顯示改寫後敘述，並以 DiffHighlight 標出與目前主敘述的差異；對照基準跟隨初始／最大切換。
