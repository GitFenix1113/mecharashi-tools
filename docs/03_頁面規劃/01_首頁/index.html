站名 ＋ 標語

MECHARASHI / Milkhama PawInfo Station 漸層大標與「獾迎你的到來！」。 左濃右淡的遮罩保證左側文字可讀，右側把背景立繪讓出來（body 的 background-attachment: fixed，全站共用）。

版本情報入口

一排膠囊按鈕（icon ＋ 名稱 ＋ →）：版本速覽 · 灰燼行動 · 版本時間線。 導覽列已經有「版本情報 ▾」，這裡再放一次是因為首頁不自帶任何資料 —— 沒有入口的話，第一次來的人會停在一個看不到內容的頁面。

第一版是一行以「·」分隔的橘色文字連結，使用者回報「看不出來是能按的」—— 可點性只靠顏色，而這站到處都是橘字。改成邊框＋淡底的按鈕之後，可點性靠**形狀**， 顏色退為強調。icon 與導覽列展開條共用同一組（VERSION_VIEWS）， 讓「這三個是同一組東西」在兩處視覺一致。

仍然不是圖示卡片格：那是這個首頁早年拆掉的東西，而且會把首頁重新變成導航頁。 現在的高度是一行（約 40px），首頁依舊是站務頁。

網站更新履歷 ＋ 維護團隊

SiteChangelog（預設三則、可展開為年／月分頁）與 SiteTeamSection（OWNER／ADMIN 頭像、LINE／Discord 社群）。

⚠️ 已移除區塊：
· 版本速覽面板（Quick Table / Gray Ops / Timeline 三分頁）—— 2026-08-19 站長定案移出首頁。理由：版本情報已是完整的一區，速覽表留在首頁永遠只能拿到 48vw、十一個欄位擠成一團，等於兩邊都做不好。首頁回歸單一職責。
· 可收合站務頂帶（HomeHeroBar）—— 收合是為了跟資料面板搶空間， 面板走了就沒有東西要搶，連同 HomeTabPanel 一起刪除。
· scroll-snap 兩頁架構（PLAN-015 的 .homepage-snap / .snap-page）—— 它把「看 Hero 還是看資料」這個離散選擇綁在滾輪／觸控板這種連續輸入上， 「輕輕滾一下就整頁彈回 Hero」是結構必然。PLAN-050 Phase B 整段刪除。
· 更早期的快速入口卡片格、公告欄、最新攻略區塊。
