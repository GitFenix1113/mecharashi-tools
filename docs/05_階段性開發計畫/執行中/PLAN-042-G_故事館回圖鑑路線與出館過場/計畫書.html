◆ PLAN-042-G

故事館回圖鑑路線與出館過場 Exit to Codex · 落款鈐印 · 關門過場

圖鑑有「故事館 ▸」，故事館卻回不去。補上三個出口（離館跟著網址走、名字旁的朱印、切換列的「圖鑑 ↗」），並讓離館播一段與「推門進館」成對的「關門」過場。

Problem
問題背景
只有單向：圖鑑 → 故事館
PLAN-042-E 在圖鑑詳情頁名字旁放了「故事館 ▸」，故事館裡卻沒有回這位機師圖鑑的路。館內唯一的出口是 header 的「離館 ↗」，落點是 /pilots 列表——得再找一次人。
分享連結、館首頁進來的人完全沒有路
只有從圖鑑進館的人能靠瀏覽器「上一頁」回去；而且館內換人用 replace，換過人之後「上一頁」回到的是進館時那位的圖鑑，不是正在看的這位。
出館是硬切
進館有「推門」（.lore-veil 深色斜切擦開，PLAN-042-C A-4），離館則是紙色瞬間換成深色站內，沒有對應的收尾。
Design
設計決策
決策一（站長 2026-10-14）：底線＋A 落款鈐印＋D 切換列按鈕，三個都做
提案比較了四個館內方案（A 落款鈐印、B 檔案分頁籤、C 卷末參見卡、D 切換列加一鈕）與一條共同底線，見 _local-notes/2026-10/2026-10-14_故事館回圖鑑路線方案/（可互動模擬稿）。 建議是底線＋A；站長加上 D：「這樣閱讀的時候也能隨時切換」——A 在標題區，閱讀模式看不到，D 的切換列在任何模式都在。B（分頁籤暗示同頁切換、預期落差大）與 C（要捲到最底）不做。
決策二（設計）：底線——「離館 ↗」跟著網址走
在 /lore/pilots/:id（含章節頁）時落點改為 /pilots/:id，館首頁維持 /pilots；標籤不變、只補滑鼠提示。 Layout.tsx 用 useMatch('/lore/pilots/:id/*') 取 id（元件式路由也能用；拿到的是解碼後的值，組網址時再 encodeURIComponent）。
決策三（設計）：A 落款鈐印——名字旁一方「機師圖鑑」朱印
與圖鑑的「故事館 ▸」鏡像對稱（都在名字旁），朱紅 #b10000 與楷體都是館內現成的語彙。白文印（紅底白字）46px、印文橫排兩行「機師／圖鑑」——傳統印的右起直排會被讀成「圖機鑑師」；印下 COMBAT DATA ↗ 小字（沿用徽章圈 caption 的樣式）。 印泥紋理是 LoreLayout 的 SVG 濾鏡 #lore-stamp（與 #lore-sketch 同處）。hover 時按壓（縮小、轉正）；完整開場的最後一拍播「蓋章」（只在 is-reveal-full 裡，換人、進出閱讀模式、開場被快轉都不重播）。 LoreDossier 也被後台預覽渲染，所以網址是選填 prop codexHref：預覽不傳＝不蓋印，管理者不會一點就被帶離編輯台。 手機收掉印下小字、印縮成 40px：五字名（淬鋒·凱登、洛莎·審判）連小字一起放不下，印會被擠到下一行（375px 實測）。
決策四（設計）：D 切換列尾端「圖鑑 ↗」
名冊鈕之後隔一條細線、紅色膠囊鈕：紅色＝離館，與館內動作（名冊，墨色）分開。手機只留圖示（同名冊鈕）。 觸控「第一下只升起列」的既有規則照樣適用——nav 的 capture 階段會先攔下點擊，連結不會被觸發。
決策五（設計）：連結指向「顯示中的那位」
印與切換列按鈕用 shown.id，不用網址的 id：換人時網址先變、舞台與卷宗落後一拍（PLAN-042-D A-6），點下去應該去畫面上看到的那位。header 只知道網址，0.3 秒的差距可以接受。
決策六（站長 2026-10-14＋設計）：出館「關門」過場
View Transitions：舊畫面（館內）原地微暗，新畫面（深色站內）以進館遮罩同一道斜邊（上 118%／下 145%）從右側蓋回來，620ms。三個出口共用 LoreExitLink（就是 <Link>，href 照常；中鍵、修飾鍵、開新視窗交回瀏覽器）。 樣式只掛在 html.lore-exiting 底下，不寫裸的 ::view-transition-*；不支援的瀏覽器與 reduced-motion 直接換頁。
⚠ 為什麼不能照教科書寫 flushSync(() => navigate(to))
React Router v7 的 <BrowserRouter> 預設把路由的 setState 包在 React.startTransition（useTransitions 沒設＝開），transition 不吃 flushSync—— update callback 結束時 React 還沒換頁，瀏覽器拍到的「新畫面」仍是故事館，整段過場等於沒播。<Link viewTransition> 也只對 data router 有效。 因此 callback 改成等 html.lore-mode 消失（LoreLayout 卸載時拿掉它＝新頁面已 commit、body 也換回深色），用 MutationObserver 而不是 rAF（callback 期間瀏覽器暫停繪製），保險絲 1.5 秒。
Scope
實作範圍與不在範圍內
在範圍內：
  • 出館過場：loreExit.ts、LoreExitLink.tsx、index.css 的 html.lore-exiting 區塊
  • 底線：Layout.tsx 的館內 header
  • 落款鈐印：LoreDossier 的 codexHref、LoreLayout 的 #lore-stamp、CSS 與開場蓋章
  • 切換列按鈕：LoreSwitcher 的 codexHref／codexName、CSS
  • 頁面規劃文件與更新履歷
不在範圍內：
  • B 檔案分頁籤、C 卷末參見卡（C 等之後真的有第二條交叉連結——例如官配機甲——再議）
  • 「從圖鑑進館、沒換過人就用上一頁回去」（保留圖鑑捲動位置）：要在圖鑑的「故事館 ▸」帶 state，且上一頁是非同步的 popstate、接不上過場；先不做
  • 圖鑑端的進館過場（圖鑑 → 故事館已有推門）
  • 機甲館（PLAN-042-B）：元件沿用，屆時把 codexHref 指到 /mechs/:id 即可
