目標效果： 網友可以把配裝存在自己的瀏覽器（10 套），並複製一串連結貼給別人，對方點開直接看到同一套配裝。完全不需要註冊、不碰 Firestore 寫入、不動 Cloudflare 後台。這是 MVP 的最後一塊 —— 完成後「網友敲碗的配裝分享」就算兌現。
最高風險：總綱決策二讓 codec 同時是儲存格式，因此 codec 的 bug ＝ 使用者資料全毀。Phase B 的三組測試與 Phase A 的 lock 檔列為驗收條件，不可跳過。

encode()：TLV 版面，含 bank 位元／§PARTS／§MODULES／元件段
2026-08-26 完成。LEB128 varint（超過 3 bytes 直接 throw——那是呼叫端的 bug，靜默截斷會產生解得開卻指錯的碼）；FNV-1a 低 8 位 checksum；base64url 不補 =，手寫而不用 btoa（後者要先轉 latin1，多一層會出錯的轉換）。
