目標效果： 擺脫 App Check／reCAPTCHA 的維運痛；公開資料防護從「可被繞的票」升級為 read: if false 真鎖；反爬改用 Cloudflare 現成基建（ASN 封機房 + 限流）；全球加速 + DDoS + 隱藏 origin；中國讀取盡量改善。成本 $0 起（唯一固定成本為一個網域）。
⚑ 灰度原則：Phase 1→2→3 必須循序，且「收緊 Firestore 規則 / 拔 App Check」（Phase 3）務必等 Phase 2 確認公開資料全數走 Worker 後才執行。Phase 4／5 為可選加值，可無限延後。每階段皆可獨立回退。
