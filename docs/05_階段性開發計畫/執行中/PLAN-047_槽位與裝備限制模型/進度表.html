src/utils/mechSlots.ts
待開始

② 全鎖型（機師形態層）：lockedSlots() 回傳該情境下完全不可調整的槽——與有沒有被佔住無關。 依據是 Q-C 答覆逐字：「不只是不能帶背包，虛粒子形態沒辦法調整任何裝備」，比 PLAN-041 引用的官方原文「無法變更武裝和技能」更強。 截圖中虛粒子形態雙肩顯示為空的 [+] 卻點不下去——該形態三把固定武裝佔的是右手／左手／背部，雙肩根本沒被佔住。
合併的代價（三條）：(a) UI 講不出「被［嵐質儲能艙］佔住」與「這個形態不能換裝備」的差別； (b) gate 行為不同——佔據型只擋該槽、全鎖型擋全部，合併後全鎖型得為每個槽塞一筆沒有 weaponId 的假佔據紀錄； (c) 落盤層級不同——佔據型是機甲資料（本計畫），全鎖型是形態資料（PLAN-041），合併會讓兩個計畫共寫同一欄位。
本計畫只交付 ①，並保證 ② 是獨立函式；② 的參數形狀與資料來源待 PLAN-041 的 forms 集合落地。
