實作時與原計畫不同的四處： ① 元件檔名是 StorySelectStage.tsx，不是 StoryStage.tsx：Windows 不分大小寫，和純函式 storyStage.ts 會被當成同一個檔（tsc TS1261）。 ② 滾輪多一道關：半秒內頁面還在捲就放行。只靠「整塊可見＋頭尾放行」的話，一路往下捲頁面的人經過舞台會被攔下來、要連換十幾章才出得去——正是 PLAN-050 捨棄的前置關卡。 ③ 冷卻改成「換章後只要滾動還連續湧入（間隔 < 160ms）就一直鎖住」：固定 260ms 冷卻擋不住觸控板一秒多的慣性（實測一次滑過 4 章 → 改後 1 章），滑鼠一格一格滾照樣一格換一章。 ④ 連帶修正 LoreLayout：換頁捲頂的 effect 依賴 [pathname, navType]，第一次用 replace 改 ?focus= 時 navType 從 PUSH 變 REPLACE，整頁被捲回頂端；改成只看 pathname（navType 用 ref 讀）。 另外：桌機的簡介原本壓在代表圖上不好讀。先試了固定形狀的紙色柔光，視窗一寬（1920、1100 實測）簡介就延伸到柔光外，站長回報看不清楚 ⇒ 改成貼著資訊區本身的紙底（文字所在處一律實色、只在右緣外與上緣漸淡）＋文字紙色光暈；「直接跳關」原本用固定 58px 裁切、第二排被切一半（站長回報）⇒ 按鈕高度與裁切高度改用 rem（跟著站上字級走）剛好露兩排，「全部 N 關」改成實際放不下才出現（ResizeObserver），舞台改 min-height 讓展開時不被切；800／1366／1920 寬 × 14／16／18px 字級實測 0 顆被切； 追加（站長同日要求試看）：館首頁的主線／活動／機師回憶改成三個分頁（?tab=，replace、與 ?focus= 並存、← → 鍵盤、上一頁回到原分頁；手機 360／375 寬三顆放得下）；章節列只顯示前後 3 章，避免最下面那章壓到操作提示。
