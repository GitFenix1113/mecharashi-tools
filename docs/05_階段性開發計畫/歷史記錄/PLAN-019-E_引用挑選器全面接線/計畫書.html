把 019-C 的 RefPicker 接進其餘既有描述面板，讓裝備／道具描述在輸入時就能把 [xxx] 標成可點引用。

前置依賴
PLAN-019-A（引用層）· PLAN-019-C（RefPicker 元件）— 皆已上線
一句話：019-A 引用層 + 019-C 的 RefPicker 已上線，但 RefPicker 目前只接在「詞條管理」與機師「技能效果」兩處。 本子計畫把同一個 RefPicker 元件接進其餘既有描述面板（模組／武器／元件／背包），並為缺欄位的型別補上 descriptionRefs， 讓資料輸入期能在編輯描述的同時把 [xxx] 標成可點引用。屬總綱 019-E「插入引用 UI」部分。
Problem
問題背景
RefPicker 只接了兩處：019-C 完成的引用挑選器目前僅出現在「詞條管理」與機師「技能效果（pilotSkills）」。 其餘帶描述的後台面板（模組／武器技能／元件／背包技能）編輯描述後，描述裡的 [xxx] 無法在後台指派引用， 仍需回頭靠工程介入填 descriptionRefs，與「讓非工程人員在輸入期一併標好引用」的目標衝突。
兩個型別還沒有 descriptionRefs 欄位：ComponentBase 與 Backpack.mainSkill 目前只有 description， 沒有對應的 descriptionRefs 可存引用 → 需先補欄位才能掛 RefPicker。（Module、WeaponSkill 已具備該欄位。）
Design
設計決策
決策一：型別補欄位（選填、向後相容）
ComponentBase 與 Backpack.mainSkill 各加 descriptionRefs?: DescriptionRefs。 Module / WeaponSkill 已有，無需動。
// src/types/index.ts export interface ComponentBase { /* …既有… */ descriptionRefs?: DescriptionRefs } export interface Backpack { /* … */ mainSkill?: { /* …既有… */ descriptionRefs?: DescriptionRefs } }
決策二：四面板掛 RefPicker（模式同 PilotSkillsTab：描述 Field 下方）
複用既有元件 src/components/admin/RefPicker.tsx，於各編輯面板的描述欄位下方插入一個 RefPicker：
  • ModuleAdmin：頂層 form.description / form.descriptionRefs（per-level 描述不掛）
  • WeaponAdmin：技能編輯器內每筆 skill.description / skill.descriptionRefs
  • ComponentAdmin：form.description / form.descriptionRefs
  • BackpackAdmin：mainSkill.description / mainSkill.descriptionRefs
決策三：零新元件 / 零新集合 / 零前台改動
寫入走既有 updateModule / updateWeapon / updateComponent / updateBackpack（皆已 stripUndefined + bumpDataVersion）。 前台 EntityRefView 在 019-C 後已能解析全部 refType（含 term），這些面板的引用顯示無需任何前台修改。
Scope
實作範圍與不在範圍內
在範圍內：
  • ComponentBase + Backpack.mainSkill 補 descriptionRefs? 欄位
  • RefPicker 接進 ModuleAdmin / WeaponAdmin / ComponentAdmin / BackpackAdmin 四面板
不在範圍內：
  • BuffAdmin（buffs 目前無後台，屬另一項工作）
  • 天賦（PilotTalent）描述編輯（目前爬蟲管理，無編輯 UI）
  • ModuleLevel per-level 描述、Weapon.description 背景故事 lore
  • BossAdmin / StageAdmin（待 PLAN-019-D）
  • 稽核 updatedBy / updatedAt（019-E 後續增量）

Verification
驗證方式
  1. 型別：npm run build 通過；新欄位皆選填、不破壞既有頁面。
  2. 接線：四面板各開一筆含 [xxx] 的描述 → RefPicker 列出 token、可指派引用、即時預覽。
  3. 持久化：儲存後前台對應頁面該詞變可點擊；未指派者原樣顯示不報錯。
  4. 查詢量：寫入後 bumpDataVersion 使快取失效；無新增集合、無前台改動。
