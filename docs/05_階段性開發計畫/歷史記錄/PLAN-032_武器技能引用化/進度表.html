計畫外實作標點全半形正規化。 SKILL_故障植入／SKILL_態勢優化 之所以需要「就地吸收」而非自動判定為同一技能， 實際原因是半形 vs 全形逗號（維護者手 key 用半形、爬蟲抓的官方文本用全形）——純輸入法雜訊。 不正規化的話，每一筆手 key 過的既有 doc 都會被誤報成「同名不同效」要人工裁決， 真正該看的跨域碰撞會被淹沒。故 normDesc 同時吃掉方括號、空白與標點寬度差異。
計畫外實作人工裁決閘門 （ABSORB_ANYWAY／FORK_AS_WEAPON 兩個名單常數，寫在腳本頂端＝進版控可 review）。 同名但描述不同時腳本不猜，列進報告並中止 --apply—— 猜錯的代價不對稱：吸收錯了會把兩個無關技能合併成一筆，而且合併後看起來完全正常。 本次實跑兩個名單皆為空（正規化後全部自動判定）。
實作時修掉的自傷 bug「空殼不得覆蓋有值」的保護 原本被呼叫端的 ?? '' ／ ?? [] 立刻抵銷—— keep() 回傳 undefined 的用意是「省略該鍵讓 merge:true 保留既有值」， 補上 fallback 等於把空值寫回去。實測 133 筆武器技能的 effects 全為空， 這個 bug 會在重跑時把 M4 之後維護者補進去的 effects/buffIds 靜默清光。 已改成 keep(weaponVal, existingVal, fallback) 三參數形式。
