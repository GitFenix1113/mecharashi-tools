◆ PLAN-021

神驅算力天賦改寫 · 算力門檻改寫天賦 · DiffHighlight

隨神經驅動算力跨越門檻，天賦正文就地改寫並引用更高階 buff；以既有 DiffHighlight 呈現各算力階差異。

範例：機師 艾達 的天賦「凝勢星爆」原引用 [凝勢I]；玩家換上「雙生星芒」神經驅動、算力跨過門檻後， 遊戲把天賦正文裡的 [凝勢I] 就地改寫成 [凝勢II/III]（可疊加 5→7 層、新增暴擊敘述）。本計畫讓站上能呈現這種「算力改寫天賦」。
Problem
問題背景
現有資料模型無法表達「算力門檻 → 天賦改寫」
PilotTalent 目前只有 description（基礎）與 descriptionMax（最大強化）兩格正文， 沒有地方放「算力 ≥ 10 版正文」「算力 ≥ 13 版正文」。descriptionRefs 也是單一對照， 無法表達「同一天賦在不同算力下引用不同階 buff」。
實機與站上落差
玩家在遊戲內看到的是被算力改寫後的天賦（顯示 [凝勢III]、7 層、含暴擊）， 站上卻只顯示基礎版（[凝勢I]、5 層），兩者對不上，玩家得自行腦補升階差異。
機制特性（升階鏈，但各階獨立）：沿算力門檻單調升階（I→II→III），但群友回報 有些詞條三階效果各不相干（LV3 可能與前階無關）。因此不宜用「同一 buff 的 tier 刻度」建模， 應視為三個獨立具名 buff。三階不共存、計算器只取最高。
Design
設計決策
決策一：天賦改寫掛在 PilotTalent.ndVariants[]（不掛 NeuralDriveLevel）
每個算力門檻對應一段「改寫後天賦正文」+ 自帶 descriptionRefs。
理由：天賦改寫是「本機師 × 本天賦」專屬資料；而神經驅動的內容層在 PLAN-004 會被抽離為共用 collection（職業共用 / 機師專屬 scope），把專屬改寫掛在共用層會汙染其他引用者。 掛 PilotTalent 後本功能與神經驅動資料模型完全解耦，PLAN-004 抽離大改不會回頭動到這裡。
// src/types/pilot.ts — PilotTalent 新增
ndVariants?: {
  minSum: number       // 算力門檻（對應 NeuralDriveLevel.minSum）
  label?: string      // 顯示用，預設由 minSum 生成「算力 ≥ 10」
  description: string   // 改寫後天賦正文（token 用該階 buff 名，如 [凝勢III]）
  descriptionRefs?: DescriptionRefs  // 此正文的 [xxx]→buff 對照
}[]
決策二：三個獨立具名 buff + 共用 mutexGroup，不建 tier 鏈
建 buff_凝勢I / II / III 三份獨立文件（群友已手 KEY），各填 effects / maxStack。 三者填同一個 mutexGroup（如 <pilotId>_凝勢），表達「I/II/III 不共存」。 GameBuff.mutexGroup 為 PLAN-019 Layer 2 既有欄位，零型別改動。
決策三：呈現複用既有 DiffHighlight 強化層
天賦卡在「▶ 最大強化」「▶ 專武強化」區塊之後，map 出 ▶ 神經驅動強化 · 算力≥{minSum} 區塊， 內用 <DiffHighlight base={天賦正文} enhanced={variant.description} refs={…} />， 自動高亮「5層→7層」「新增暴擊」。與 PLAN-005 專武強化視覺一致，玩家零學習成本。
邊界：LV3 可能與前階無關
若改寫正文與基礎差異極大，DiffHighlight 會高亮一大片——這是優雅退化，正好告訴玩家「這階差很多」，不會壞。 因三 buff 名稱不同，token 字串天然不撞，一張 descriptionRefs 即可全收。
計算器「取最高」如何成立（給未來，不在本計畫實作）：選定算力 → 取 minSum ≤ 算力 的最高神驅 level → 其 buffIds → mutexGroup 收斂成單一生效階。「最高」由 minSum 推導，無需在 buff 上加 tier 欄位。
Scope
實作範圍與不在範圍內
在範圍內：
  • PilotTalent.ndVariants[] 型別新增
  • 三階 buff 補 mutexGroup（資料層，後台填）
  • 後台：天賦編輯器加「算力階天賦改寫」輸入 UI（任務 3-1，2026-06-12 完成）——NdVariantsEditor（zone 下拉防呆 + 兩版正文 + RefPicker）+ manual 勾選框；編輯器走共用 RefPicker，PLAN-022 Phase C 上線時自動獲得「代入數值」、無返工
  • 前台：PilotDetailPage 天賦卡新增神驅強化 DiffHighlight 區塊
  • docs 同步：02_資料模型 pilot 頁、04_Firebase pilots 集合文件
不在範圍內：
  • 神經驅動節點庫抽離（neuralDrives Collection、職業共用 / 機師專屬 scope）→ 已屬 PLAN-004，獨立進行，本計畫不依賴它
  • 互動式算力切換器（segmented control / token 化正文）→ 維護負擔過高，已否決
  • 計算器整合（取最高 / Buff 面板）→ 屬模擬層，留待 PLAN-019 後續
  • 爬蟲自動側錄各算力階正文 → 走 manual 手動維護（資料源為官方 WIKI，群友三週一隻補）
