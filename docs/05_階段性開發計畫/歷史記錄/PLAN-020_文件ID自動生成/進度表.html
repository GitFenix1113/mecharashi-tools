✅ 已完成（2026-06-09 歸檔）： 新建 BUFF 時 ID 一律由系統生成（buff_<名稱>），維護者只需輸入名稱與分類，並在建立當下擋下同名 / 同 ID 重複——不論誰來維護、程式水平如何，都不會再產生命名歧異。舊資料維持原狀。 收尾另追加兩項防呆：撞名比對不分大小寫（擋 buff_x／BUFF_x 大小寫孿生），以及維護者誤打 buff_ 前綴時自動消除（stripIdPrefix）。 純函式以 node --test 單元測試守護（8/8）。
