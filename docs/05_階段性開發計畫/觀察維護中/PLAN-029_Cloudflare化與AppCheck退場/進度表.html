P4   圖片快取（R2 已由 Cache Rule 取代）
Cache Rules · R2（擱置）
實質結案
4-0 Cache Rule：/images/* 邊緣 TTL 覆寫
在 zone 加一條 Cache Rule，忽略 origin 的 cache-control、將邊緣 TTL 設為 7 天，取代原本 R2 方案的絕大部分效益。
✅ 已完成（2026-07-26）：條件 starts_with(http.request.uri.path, "/images/")、快取資格「適用快取」、邊緣 TTL「忽略 cache-control 並使用此 TTL」＝ 604800 秒；瀏覽器 TTL 刻意不動（維持遵循 origin 的 4 小時，留一個自我修復窗口）。
為何需要：GitHub Pages 只回 max-age=14400，且每次部署都會重寫整個 gh-pages 分支——2340 張圖、188MB 的 ETag／Last-Modified 全部改變，即使內容沒動。結果是每次部署都把圖庫的邊緣快取打掉、反覆回源。覆寫後部署不再沖掉快取。
