# 機甲戰術手遊《鋼嵐》封測報名開跑  機師火熱募集中
# 2024-03.25
# https://ma.tentree-games.com/jx/maNews/20240325/5909.html

機甲戰術手遊《鋼嵐》封測報名開跑 機師火熱募集中
將於第二季上市的機甲戰術手遊《鋼嵐》宣布即日(25)起展開封測報名，招募各路機師好手與機甲們並肩作戰，一同譜寫這場淘金洪流中的狂嵐序曲。
價值一萬點券每日領 再送封測限定專屬徽記
為了讓機師們有良好的遊戲體驗，封測期間每日送價值1萬元點券，更能獲得封測限定專屬徽記！不僅能搶先體驗塗裝功能，還能在遊戲上市後擁有限定徽記，為你的機甲增添個性化的造型設計；想一同馳騁戰場享受極致的視覺饗宴嗎？立即前往報名頁面加入機師招募的行列！
報名時間：即日起 ~ 4/7(日) 23:59
封測時間：4/11(四) 11:00~4/15(一) 11:59
測試平台：Google Play商店、iOS TestFlight以及PC版
即刻報名封測
戰棋新視界 策略佈局不受限
擺脫過往戰棋遊戲中常見的「屬性剋制」機制，轉而強調不同機師的職業特性以及個性化的策略布局，《鋼嵐》的核心特色除了部位破壞玩法，可以針對右臂、左臂、軀幹以及雙腿進行瞄準擊破，限縮敵方的武器使用能力以及閃避機動性之外，還加入了命中率的不定因素，增加了對戰的刺激感，也能隨著戰鬥的條件和職業差異，進行攻擊威力預測以及行動點的配置。
機師六大職業 機甲三大量級 多元布陣作戰
《鋼嵐》中的機師分為六大職業：突擊手、格鬥家、狙擊手、戰術家、機械師與守護者。突擊手以攻擊輸出為主，搭配核心機制「協力攻擊」可大幅削減敵方血量；格鬥家與狙擊手定位相近，區別在於射程範圍以及行動點的限制條件；戰術家以範圍攻擊為特點、機械師與守護者則分別擔任團隊中「奶媽」以及「坦克」的角色。雖有職業上的定義，在遊戲中卻保留一定的自由度，不僅可以依據機師的駕駛許可進行對應機甲的搭配，更可根據戰鬥的需求裝配不同的武器，再再給與了玩家們高度自由的遊玩體驗以及自訂義戰局的彈性與空間。
更多《鋼嵐》的遊戲資訊、抽獎活動將陸續於官網、粉絲團等官方帳號同步公開，有興趣的玩家請追蹤並持續關注相關社群獲得第一手消息。
