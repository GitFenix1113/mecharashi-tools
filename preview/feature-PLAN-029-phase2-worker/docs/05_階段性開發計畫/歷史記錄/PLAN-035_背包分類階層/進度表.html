tierFromRarity + 名字解析（強化/干擾/變體）
tierFromRarity(rarity) → 'material'|'base'|'composite'|'special' （A/B→material · S→base · S+→composite · SS→special）。
parseBackpackName(name) → { baseFunction: string|null, line: '強化'|'干擾'|null, variant: string|null }： 名字結構 [基礎功能]?[強化|干擾]背包·[變體] 可乾淨拆；純功能背包與 SS 特種背包 line=null。
⚠ baseFunction 須容許 null——base 階 強化背包·首攻/干擾背包·攻擊 無基礎功能前綴（type=Enhance/EMP）， 只有 S+ 複合階才有 出力/移動… 前綴。
⚠ line 一律從 name 判斷，不可用 type （出力強化/出力干擾背包同 type=PowerAdd）。附中文標籤對照與純函式單元測試。
