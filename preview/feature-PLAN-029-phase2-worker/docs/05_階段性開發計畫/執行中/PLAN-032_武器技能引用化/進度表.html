Acceptance
驗收條件
  • 武器詳情頁／圖鑑／模擬器的技能顯示與 buff 計算與遷移前完全相同（純結構重整）。
  • 技能庫中武器技能為 124 筆（或 live 重跑後的實際值），無同名重複 doc。
  • 起爆／凝神待發 等原本漂移的技能只剩一份定義， 且文字為含方括號的版本。
  • 在技能庫改一筆武器技能的效果 → 所有持有它的武器同時更新。
  • 武器技能可被任意描述以 [起爆] 引用並正確解析。
  • 技能庫尚未載入時，武器頁不出現空的技能區塊（5 處 .length gate 已修）。
  • npm run build 通過；node --test 通過。
  • M6 後在無痕視窗確認雙 bump 生效、資料正常。
