parseBackpackName(name) → { baseFunction, line: '強化'|'干擾'|null, variant: string|null }： S+ 名字結構 [基礎功能][強化|干擾]背包·[變體] 可乾淨拆；純功能背包與 SS 特種背包 line=null。
⚠ line 一律從 name 判斷，不可用 type （出力強化/出力干擾背包同 type=PowerAdd）。附中文標籤對照與純函式單元測試。
