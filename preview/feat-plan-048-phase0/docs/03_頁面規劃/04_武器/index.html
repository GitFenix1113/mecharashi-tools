「固定武裝」為什麼預設不顯示
固定武裝是焊死在機體上、無法更換也不能裝元件的武器（衝擊炮／嵐質儲能艙／多功能彈倉／耀星／隕星／千星，共 6 件）。 圖鑑的定位是「查得到」，但這六件不該混進一般武器的統計與排序—— 它們的稀有度都是 S，不排除的話會安靜地混在 S 級武器中間； 搜尋也吃武器種類，搜「彈倉」會跳出根本不是玩家武器的東西。
因此採預設隱藏 + 單獨開關：關閉時總數、搜尋結果、部位計數、稀有度排序完全等同於沒有這六件 （連「全 N 把」的基數也跟著開關走，不會洩漏隱藏筆數）；打開後它們才進入所有計算，並各自帶上 🔒 固定武裝 標記。

武器 Hero 區塊

武器名稱、稀有度標籤（SS / S+ / S / A / B）、大類 / 種類標籤、機甲限制標籤（無限制 / 輕型 / 中型 / 重型）、裝備部位標籤（單手 / 雙手 / 肩膀 / 背後）。
固定武裝另掛 🔒 固定武裝 標記（橘色）。刻意不與專武的金框 + ⭐ 相像——兩者語意相反：專武是「可選裝的獎勵」，固定武裝是「鎖死的限制」，看起來一樣會讓人把限制誤讀成獎勵。
數值面板對遊戲中本來就沒有數值的欄位顯示「—」而非 0（如嵐質儲能艙全欄、衝擊炮的攻擊/命中/暴擊/重量/種類係數）。這是必要的：本站以「彈藥量 0」表示無限彈藥 ∞，照填 0 會把「沒有彈藥」渲染成「無限彈藥」，與遊戲相反。

基礎屬性面板

攻擊力（含子彈數，如 766×1）、命中值、暴擊值、重量、射程（manhattan / orthogonal 顯示 "2-4"；ring 顯示 "2+"）、彈藥量、連擊數。

技能列表（縮圖 / 展開）

每個技能以圖示縮圖 + 名稱呈現，可點擊展開完整描述（PLAN-021 改版）。卡片顯示：生效方式標籤（攜帶=紫 / 裝備中=青 / 使用時=橘）、文字描述、結構化效果數值。
若技能有 enhancesTalentName，顯示「強化天賦」區塊（黃色 DiffHighlight）。

🔧

改裝資訊

固定改裝：方案名稱、可改等級上限、固定效果列表（stat + value）。
浮動改裝：方案名稱、可填欄位數、所有可能效果（含觸發條件與 min ~ max 範圍）。

元件插槽資訊

觸元件插槽數 / 應元件插槽數、元件上限（componentLimit）顯示。以小格子圖示呈現，空格可視為可用槽位。

⭐

專武資訊（isExclusive=true）

顯示對應機師名稱及連結（exclusiveFor）；技能區塊會額外呈現天賦強化 DiffHighlight，讓使用者直觀看到「有此專武時天賦的強化版本」。

⚗️

製作 · 進階關係（PLAN-031）

「前置 ← 本武器 → 可進階為」進階鏈：由 upgrade.fromWeaponId 前端建正/反向索引（buildUpgradeIndex），覆蓋全站 42 條製作邊、皆可點擊互連。技能列表並標示「進階新增 / 融合技能」（母子武器技能名差集，即時計算）。
複合武器（upgrade.station==='specialBackpack'）額外顯示「特種背包製作」badge 與「融合自 ○○背包」（fusedBackpackId 查表；只在複合武器頁才載入 backpacks）。無 upgrade 值時整區不渲染。

🔗

數值引用層（PLAN-019 / 022）

技能描述中的 [xxx] 實體引用（buff / 技能 / 詞條）以可點擊樣式呈現，桌面 hover 浮窗預覽、點擊釘選，手機 BottomSheet（ReferenceContext）；<refId.attr> 數值引用顯示 BUFF 屬性真值。需 WeaponSkill.descriptionRefs 側錄表，未命中原樣顯示。
