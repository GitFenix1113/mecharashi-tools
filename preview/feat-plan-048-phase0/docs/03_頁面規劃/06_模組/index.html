模組卡片

模組圖示、名稱、稀有度標籤（S/A）、槽位標籤（特性/8級/通用/副模組）。描述文字中的數字與 % 符號以紅色粗體標示（highlightNumbers()）。
卡片本體由共用元件 components/module/ModuleCard 產出，與機甲詳情頁的模組區同一份實作（variant 區分圖鑑版／詳情頁版）。

📊

各等級效果（內嵌選擇器）

PLAN-044 改版：等級效果直接顯示在卡片上，不再是懸浮視窗。卡片內附等級選擇器（桌機為滑桿並顯示 Lv.N/M，行動裝置為等級按鈕列），切換後描述文字與數值標籤同步跟著該等級變動。
預設落在滿級；等級狀態各卡獨立，不做全頁連動（模組等級上限不一致）。只有一級或無等級資料時選擇器整個不渲染。

🗂️

各等級一覽（「全部」按鈕）

選擇器右側的 「全部」小按鈕可開出「各等級效果」浮窗，一次列出每一級的描述與數值——滑桿負責查閱單一等級，此處負責跨等級比較（哪一級跳幅最大）。
桌機為可拖曳浮窗（標題列拖動、ESC／✕／點外部關閉，多張卡可同時開著並排比較）；行動裝置改開 BottomSheet。
高度上限給到整個視窗高度而非固定比例：螢幕夠高時 8 級一次看完不捲動，放不下才退回捲動並貼齊視窗把高度用滿；視窗寬 ≥ 1024px 時浮窗加寬至 360px（換行變少、整體更矮）。當前選取的等級在一覽中高亮。與舊版的差異：只由按鈕開啟，不再 hover 觸發，也不與卡片點擊耦合。實作於 components/module/ModuleAllLevels。

📍

數值標籤 & 來源

卡片底部顯示當前選取等級的非零數值標籤；值為 0 或未設定的欄位不渲染，整組皆空時連容器都不出現。
標籤對照表 STAT_LABELS 以 Record<StatKey, …> 型別窮盡（ModuleLevel 新增數值欄位而未補標籤會編譯失敗），涵蓋基礎屬性、武器類別增傷與武器種類增傷共 32 個欄位；武器相關標籤直接引用 WeaponType / WeaponKind enum，與武器圖鑑用語保證一致。
來源欄位顯示 source 陣列。拆解來源機甲（dismantleMechIds）刻意不顯示——「特性模組在誰身上，拆他就有」屬玩家常識，不在介面上解釋；該欄位僅後台可編。

🤖

採用機甲

顯示採用此模組的機甲縮圖列（可點擊前往該機甲詳情頁；縮圖載不到時退回機甲名文字 chip，不留白）。
由機甲端 module4Id / module8Id / moduleFixedIds 正向引用反查建立索引（hooks/useModuleAdopters）；含 8 級模組多機甲共用情形。反查落空時退回模組自身的 boundMechId。
※ 舊版依機甲數量在「對應機甲／採用機甲」兩種文案間切換，兩者實為同一份資料，已統一為「採用」。

📐 版面與排序 格線卡片（1 欄 / 平板 2 欄 / 寬螢幕 3 欄）。篩選列固定於內容區頂部，不含側欄。
排序：特性模組 → 8級模組 → 通用模組（副模組勾選顯示時排最後）；順序由 utils/moduleSlots.ts 的 CATALOG_SLOTS 陣列定義，與篩選按鈕共用同一份。同槽位內維持 Firestore 原始順序。
稀有度預設篩選 S（可按「全部」放開）。
機甲專屬模組（slot = "機甲專屬模組"）永遠排除，不顯示於圖鑑。
